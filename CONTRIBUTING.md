# Contributing

## Development

1. Clone the repository.
2. Open the project in your editor.
3. Make focused changes to the HTML, CSS, or JavaScript.
4. Test the chat flow in a modern browser.

## Quality Checklist

- Keep the interface responsive.
- Preserve Turkish UI text and existing user flows.
- Validate user input before adding content.
- Avoid introducing unsafe HTML rendering.
- Test modal, contact, message, profile, and sound controls after changes.

## Pull Requests

Use a short, descriptive title and explain what changed and how it was tested.
